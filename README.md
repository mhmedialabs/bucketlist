# Bucketlist

A personal bucket list tracker to help you capture, organize, and achieve the experiences and goals that matter most to you.

## Features

- **Add goals** — Create bucket list items with titles, descriptions, and categories
- **Track progress** — Mark items as in-progress or completed
- **Organize** — Filter and sort by category, priority, or status
- **Set deadlines** — Attach target dates to keep yourself accountable
- **Reflect** — Add notes and memories once an item is completed
